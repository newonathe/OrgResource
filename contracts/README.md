# Contract artifacts

The current public route and DTO contract is [05_API_26_ROUTES_AND_RESPONSES.md](../docs/complete-handoff/05_API_26_ROUTES_AND_RESPONSES.md). It governs the five-entity implementation and the 25 original routes plus separately identified A09.

`operations.json`, `domain-model.json`, and `response-examples.json` were produced for the earlier nine-entity, 68-operation planning scope. They are retained for provenance and are historical, not current implementation instructions. Do not use their fields, actors, or route definitions to expand the current application.
