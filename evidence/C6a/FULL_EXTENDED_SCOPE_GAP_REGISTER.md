## Conflict and supersession register

- **Edition/version.** Frozen Course A uses Java 8, the original Jersey/Spring controller pattern, Javax, JPA, MySQL and Retrofit/Gson. Extended uses the approved compatibility runtime, preserves literal Javax checks and has additional operational tables. Jakarta runtime and Javax validation are separate integration points.
- **Counts.** Five original business families in both editions. The reporting reads/exports and identity/ledger support are Extended work. Count original 26 business operations plus the two academic image operations separately. Do not count path annotation equivalence as verified behavior.
- **Historical vs modern API.** Intended CP35 tenant v2 CRUD, roles and ETags depend on explicit owner decisions and their own tests. A legacy connection through a protected org session does not complete every modern route.
- **Roles, names and assignment.** The approved minimum activity/export uses OWNER/ADMIN. Borrower names are labels. LEAD does not turn a claim of an assignment into data access. Wider activity audit, borrower linkage and Project assignment require approved row-scoping before UI exposure.
- **Stock and lifecycle.** Reusable physical total minus active holds and issued custody. Consumable physical total minus active holds. Return and consume differ. The immutable movements and existing compatibility responses preserve the mathematical invariant.
- **Reminder semantics.** Existing recorded outcomes reflect observed dispatch decisions. Neither the fake client nor provider-shaped loopback establishes delivery. Consent can revoke contact data; Course A's historical proposal difference is preserved.
- **Pagination and exports.** Cursor traversal, search, complete aggregate downloads, and partial list UI are different claims. Initial exports are three bounded read-only datasets with explicit refusal rather than truncation.
- **Release, restore and deadlines.** Exact package SHA, C6a branch and final evidence commit may differ only in intentionally subsequent evidence updates. Local process isolation does not imply off-host readiness. The printed academic deadline and current Canvas deadline need separate verification.
