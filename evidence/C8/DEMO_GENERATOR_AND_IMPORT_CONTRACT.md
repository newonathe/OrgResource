# C8-D local-only synthetic dry run

The owner approved the 96 directory labels as a local demo input on November 19, 2026. The implementation uses dated first-party organization labels and fictional operational activity. It includes 72 COA-M directory entries of mixed entity types and 24 verified LIONS entries. It resolves nine aliases, excludes eight historical references and omits the additional LIONS umbrella card from this cohort. That count documents the chosen reference cohort. [COA-M RecWeek directory](https://ateneorecweek.org/coa-m-orgs) · [LIONS RecWeek directory](https://ateneorecweek.org/lions-orgs).

The local-only source manifest SHA-256 is `57f1f0c680041c39dcf7644a1acca5fcc75dc7d525262547842389da7540b9a2`. It was regenerated byte-for-byte. It keeps short factual names, direct links, the source revision and source input hashes. The filing avoids real individuals, private contacts, photos, institutional marks and factual claims about the simulated activity.

Run `python scripts/generate-c8-demo.py --source <local-manifest.json> --source-sha256 <digest> --seed c8-course-demo-2026-v1 --output <local-destination.json>`. It generates stable IDs and per-organization ordered business actions within the fixed December 2025–November 2026 history. The workload uses the lower bound of each approved tier. The in-memory validator checks identity, scope, timestamps, allowed transitions, physical quantity, approved holds, issued custody and Requirement coverage. A mismatched source hash was tested and refused before output.

Two runs produced a 19,265,850-byte plan with SHA-256 `3b0f54da85cadb77cd7d8ab2d50c1fdb4b4ee36710b803cf904227e13f08927c`. It contains 96 profiles, 248 Departments, 713 Projects, 1,312 Resources, 2,139 Requirements, 462 fictional persona definitions, 21,060 Allocation requests and 67,370 ordered business actions. All six terminal status families and all twelve calendar months are represented.
