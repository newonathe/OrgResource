# C8 bounded authorization acceptance contract v1

The owner revised the optional Extended C8 verification method after IR4. The 22,320-case historical ledger retains its original case IDs and results. A new route-based ledger records evidence under this contract. No academic requirement, inventory invariant, privacy restriction or confirmed material defect is waived.

| Required evidence | Closure rule |
| --- | --- |
| Actual route inventory | Match registered Jersey resources against source and packaged handlers, including HTTP methods, media types and delegates. |
| Route policy | Independently review authentication, tenant and object scope, eligible roles, lifecycle, preconditions, allowed fields, denials and database effects for every operation. Build the oracle before running the request. |
| Operation verification | Protected operations require an authorized request and a meaningful refusal. Supply a real existing target where a tenant or object rule applies. Public operations require verified intended behavior and privacy checks. |
| Distinct rules | Exercise role boundaries, selected versus path workspace, current membership and revocation, assigned Project, borrower linkage, contact redaction, stock lifecycle, reporting and exports, receipts and replay. Use routed service checks where middleware cannot establish these distinctions. |
| Writes and concurrency | Verify status, minimal disclosure and exact relevant MySQL postconditions for denied high-risk writes. Authorized writes must affect only approved state. Retain directed checks for concurrency, rollback, receipt expiry, revoked permissions and restart persistence. |
| Supporting interactions | Record factors, constraints and measured interaction coverage for any combinatorial suite. Pairwise coverage is limited to its named model. |
| Independent review | A separate reviewer examines the design before execution and checks route policies, fixture state, code and receipts before acceptance. An open mandatory item blocks acceptance. |
| Release evidence | Retain independently verified restore proof when storage and recovery semantics match. Preserve Course A and require all hosted jobs green at the exact final remote revision. |

The private working ledger and detailed receipts remain in the restricted evidence packet. This contract grants no permission for hosting, redistributing course materials, using live SMS, or submitting coursework.
